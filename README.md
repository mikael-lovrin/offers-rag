# Offers RAG — Funnel of the Week Semantic Search

**Autor:** Mikael Lovrin  
**Licença:** [CC BY 4.0](LICENSE)

Agente que busca (via RAG) padrões de ofertas já validadas na base "Funnel of the Week". Encontra cases similares ao seu nicho/produto.

---

## Requisitos

[Claude Code](https://claude.com/claude-code) + Acesso a Knowledge/FunnelOfTheWeek/

---

## Instalação

Rode `Install.bat`

---

## Como usar

Descreva seu nicho/produto — retorna ofertas similares validadas + como foram estruturadas + resultados.
